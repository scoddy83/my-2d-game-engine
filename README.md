# 🎮 Mein erstes 2D Spiel — Jump & Run Platformer

> Ein selbst entwickeltes 2D Jump & Run, gebaut auf einer eigenen 2D Game Engine.  
> Dieses Projekt ist Teil meiner persönlichen Lernreise als Spieleentwickler.

---

## 📖 Über das Projekt

Dieses Spiel ist mein erstes vollständiges 2D-Spielprojekt. Es ist ein klassischer **Jump & Run Platformer** — eine Gattung, die scheinbar einfach wirkt, aber nahezu alle wichtigen Systeme einer Game Engine herausfordert:

- **Physik & Kollision** (Gravitation, AABB-Tile-Kollision)
- **Input-Handling** (präzise Steuerung, Sprungpuffer)
- **Tilemap-System** (Level-Design aus Kacheln)
- **Kamera** (scrollende Welt, die dem Spieler folgt)
- **Sound & Feedback** (Sprung, Landung, Treffer)

Das Projekt entsteht **von Grund auf** — inklusive der darunterliegenden 2D Engine.
